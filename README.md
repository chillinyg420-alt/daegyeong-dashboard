# 대경지역 매출자료 대시보드 — GitHub 페이지 올리는 방법

이 폴더의 `docs` 안 파일 4개가 대시보드 전체입니다. 설치할 프로그램은 없고, GitHub 웹사이트에서 클릭만 하면 됩니다.

## 1. 저장소 만들기 (처음 1회)
1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**
2. 이름 입력(예: `daegyeong-dashboard`) → **Create repository**
   - Public / Private 어느 쪽이든 괜찮습니다. 자료는 암호로 잠겨 있어 암호 없이는 읽을 수 없습니다.

## 2. 파일 올리기
1. 만든 저장소 화면에서 **uploading an existing file** (또는 Add file → Upload files) 클릭
2. 이 zip을 풀고 **`docs` 폴더째** 끌어다 놓기 → 아래 **Commit changes** 클릭
   - `docs` 안에는 `index.html`, `app.js`, `data.enc.json`, `.nojekyll` 이 있어야 합니다.
   - ⚠️ 점(.)으로 시작하는 `.nojekyll` 파일이 보이지 않으면, 폴더째 올리기 대신 파일 4개를 `docs/`에 각각 올려 주세요.

## 3. 페이지 켜기
1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch** / Branch: **main** , 폴더: **/docs** → **Save**
3. 1~2분 뒤 같은 화면에 `https://내아이디.github.io/저장소이름/` 주소가 나옵니다. (비공개 저장소의 Pages는 GitHub 유료 요금제에서만 가능하며, 무료 요금제는 공개 저장소를 쓰시면 됩니다.)

## 4. 사용법
- 주소 접속 → **암호 입력**(암호는 별도 전달) → 위쪽에서 **기준(합계/매장매출/재고통합)**, **구분(누계/월)**, **대상(지역 전체/지점)**, **탭(브리핑·매장 TO DO·요약·분류별·브랜드별·재고·시간대별·인시생산성)** 선택
- 모든 화면에 금년·전년·전년비가 함께 나옵니다. 휴대폰에서도 같은 주소로 열립니다(홈 화면에 추가 가능).
- 요약 탭의 지점 표에서 지점을 누르면 그 지점으로 바로 이동합니다.

- 브리핑(월간 핵심 현황·주요 변화·AI 해석·월간 리포트), 매장 TO DO(매장별 상태·원인·할 일), 재고(재고 증감·재고주수·건강도·과부족 점검)는 최신 마감월 기준이며 매월 갱신 때 새로 작성됩니다.

## 5. 보안 안내 (중요)
- 매출 자료는 **AES-256으로 암호화**된 `data.enc.json`에만 들어 있습니다. 암호 없이는 읽을 수 없습니다.
- 암호는 12자 이상 무작위 문자를 권장합니다. **암호를 잊으면 복구할 수 없고**, 새 암호로 파일을 다시 만들어야 합니다.
- 암호를 아는 사람은 누구나 자료를 볼 수 있으니 공유 범위를 관리해 주세요. 암호 변경이 필요하면 새 암호를 알려주시면 파일을 다시 만들어 드립니다.

## 6. 매월 갱신
새 원본 데이터를 올려주시면 **`data.enc.json` 한 파일만** 새로 만들어 드립니다. 저장소에서 같은 이름으로 다시 업로드(덮어쓰기)하면 끝입니다.

## 7. 알아 두실 점
- 기준: **합계 = 매장매출(offline) + 재고통합(online)**. 맨 위 [기준] 버튼으로 바꿉니다.
- 요약: 3개 기준 모두 제공. 구매전환율 = 매장 구매객수 ÷ 매장 입점객수(온라인 제외). 객단가는 합계·오프라인(매장매출÷매장객수)·온라인(재고통합매출÷재고통합객수) 3가지로 표시. 인시생산성: 합계·매장매출만 제공(재고통합은 해당 없음), 지역장 근무는 전 매장 제외.
- 시간대별(전자저널)은 매장매출만 제공합니다. 1~9월·누계 모두 금년/전년 비교, 09:30~22:30만 표시(09:30~12:00·20:00~22:30은 30분, 12:00~20:00은 1시간 단위).
- 재고는 재고현황 파일의 기말 재고 수량입니다(월=해당 월말, 누계=9월말). 분류별은 스타일 코드로 판매 분류에 매칭했고, 브랜드별은 신발 재고입니다.
- 분류별·브랜드별의 합계/재고통합 기준은 판매상세에 재고통합 내역이 있는 9개점만 분류됩니다. 나머지 점의 재고통합은 분류별 표 맨 아래 '분류 불가' 행으로 표시되며, [분류 가능분 + 분류 불가 = 월 KPI 합계]로 일치합니다.
- 암호는 이 파일에 적지 않았습니다(별도 전달).
