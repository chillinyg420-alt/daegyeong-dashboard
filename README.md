# 대경지역 매출자료 대시보드

주소: https://chillinyg420-alt.github.io/daegyeong-dashboard/ (접속 암호는 별도 전달)

## 사용법 (점장·지역장 공통)
- 처음 열면 **내 매장**을 한 번 고릅니다 → 다음부터 그 매장 현황판이 첫 화면으로 열립니다(이 기기에만 저장).
- 다른 매장은 위쪽 **대상**에서 바꿔 보고, **🏠 버튼**으로 내 매장에 바로 돌아옵니다. 내 매장 변경: 오른쪽 위 **🏠 내 매장 설정**.
- 암호 입력 때 **이 기기에서 암호 기억**을 체크하면 다음부터 암호 없이 열립니다(본인 휴대폰·PC에서만 사용). 지우려면 **🔒 잠그기**.
- 메뉴는 4개입니다: **현황판**(목표 달성·요인 분해·매장 신호등·동업계·행사) · **매장 비교**(요약·순위/시간대별/인시생산성) · **상품·재고**(분류별/브랜드별/베스트상품/재고) · **상권·AI**.
- 위쪽 **기준(합계/매장매출/재고통합)**, **구분(누계/월)**을 골라 봅니다. 매출·재고 비중이 모두 2% 미만인 작은 항목은 연하게 표시됩니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html`, `app.js` | 화면과 기능 |
| `manifest.json` | 자료 조각 목록(자료·암호 없음) |
| `d/*.bin` | 매출 자료 조각 5개 — **압축 후 AES-256 암호화**. 핵심(약 70KB)을 먼저 열고 나머지는 뒤에서 이어 받습니다 |
| `fflate.min.js` | 오래된 휴대폰용 압축 해제 도구(필요할 때만 불러옴) |
| `html2canvas`, `jspdf`, `xlsx-style` | PDF·엑셀 받기 기능(누를 때만 불러옴) |
| `data.enc.json` | 예전 방식 자료(호환용, 다음 갱신 때 삭제 예정) |
| `build/` | 매월 자료를 만드는 계산 방법(스크립트) — 자료·암호는 들어 있지 않음 |

## 매월 갱신
원본 데이터를 올려 주시면 Claude가 자료를 만들어 이 저장소에 **직접 반영**합니다(별도 업로드 작업 없음). 반영 후 1~2분 뒤 주소에 적용됩니다.

## 보안
- 매출 자료는 암호화된 `d/*.bin`에만 있으며 암호 없이는 읽을 수 없습니다. 암호는 이 저장소에 저장하지 않습니다.
- 암호를 아는 사람은 누구나 자료를 볼 수 있으니 공유 범위를 관리해 주세요. 암호를 바꾸려면 새 암호로 자료를 다시 만들면 됩니다.

## 알아 두실 점
- 합계 = 매장매출(offline) + 재고통합(online). 구매전환율 = 매장 구매객수 ÷ 매장 입점객수(온라인 제외).
- 시간대별(전자저널)은 매장매출만, 09:30~22:30. 인시생산성은 지역장 근무 제외.
- 전년비는 전년 같은 달 실적이 있는 매장·월끼리만 비교합니다(신규 오픈·리뉴얼 달 제외, 기준: 매장 정보 MASTER). 실적은 전부 표시합니다.
- 브리핑·재고 분석 문장은 매월 갱신 때 새로 작성됩니다. 매출·재고 비중이 모두 1% 미만인 작은 항목은 문장에서 뺍니다.
